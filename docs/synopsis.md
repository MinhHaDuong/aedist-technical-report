# Synopsis — Beyond RAG: Stateful-Agentic Architectures for Reliable Economic Statistics

Reliable economic statistics are critical infrastructure for applied modelling, and nowhere more so than in the energy transition. Open energy-system models such as PyPSA-ASEAN need power-plant inventories that are complete, accurately dated, and traceable to primary sources — enabling quasi-real-time support for policy analysis in countries where the data landscape changes faster than publication cycles. Yet across most of the world the relevant facts arrive late, incomplete, or under licences that forbid redistribution, even though the underlying information is already public — scattered across project documents, master plans, environmental assessments, operator reports, and press releases. The general problem behind the specific one is older than AI: science needs knowledge, not opinions. Statistical work requires facts that are sourced, reproducible, and auditable, not plausible outputs from a black box.

This paper builds the argument in six steps.

First, the baseline. Submitting a direct query to a large language model produces an inventory-shaped answer, but not one that meets statistical or scientific quality standards. Numbers shift between runs, citations are absent or fabricated, and there is no way to tell which cells one should trust.

Second, the quality bar that any acceptable system must clear. Four properties define it. *Accuracy* asks whether the table contains all assets (recall), only assets (precision), and the correct attributes per asset. *Coherence* asks whether extracted cells are internally consistent: cross-row values do not contradict, and aggregate totals match per-plant sums. *Provenance* — in standard terms, attribution and faithfulness — requires that each cell traces to a specific row of a specific source table; that ideally two independent primary sources back each asset; that citations are verified rather than merely verifiable — aspirational but non-negotiable in v1; that attribution is per-cell rather than per-row; and that the procedure is independent of any single model and incrementally updateable when new documents appear. *Temporality* follows from the nature of energy infrastructure: every value carries a best-effort as-of date, with notable status changes flagged in a notes column; full historical trajectories and scenario projections are the province of the energy model, not the statistical tool.

Third, the industry trajectory. The progression is a DAG, not a strict chain: web access and reasoning are parallel branches that converge at deep research. Prompt engineering and multi-turn exchange close Articulation; retrieval-augmented generation closes Coverage; web access closes Freshness — structurally present in the deep-research cell, though measuring whether retrieved data is more current than the training cutoff remains future work; and reasoning closes Coherence. Each branch closes one named limit.

Fourth, we predict the frontier will still fall short on the method bar. H3 conjectures that a state-of-the-art cloud agent given everything in one prompt — extended reasoning, web access, a fully specified extraction prompt — at roughly ten dollars per overnight run will achieve acceptable recall, yet still fail the full attribution and provenance requirements: citations verifiable but not verified, attribution per-row not per-cell, no as-of date recorded per value.

Fifth, the full requirements imply a specialised architecture, not a heroic single prompt. Such a system must be stateful, agentic, capable of per-cell provenance with as-of dates, runnable on local models for sovereignty and cost, and updateable without re-extracting the world. Each cell is a claim: a (source, date, confidence, conflict-resolution history) tuple, not a bare value. Whether a well-chosen local open-weight model achieves this without the full deep-research stack, or whether parametric extraction on a well-suited model already suffices, remains to be explored (H4).

Sixth, a theoretical frame locates the contribution. Fusing competing source tables into one inventory is structurally analogous to fusing knowledge-graph triples: same subject-predicate-object shape, same conflict-resolution problem. Cases that challenge rule-based systems — assets evolving through lifecycle stages, sources of varying authority, multilingual records, conditional projections — are precisely where language-model reasoning adds value over schema-fixed rules. This paper implements per-cell provenance using LLMs and structured tables; graph databases remain a natural next layer for future work.

Four hypotheses make this argument empirical, tested against a hand-curated reference inventory of Vietnam's thermal power sector where contested values were resolved against primary sources: H1 and H2 — each rung of the method ladder adds measurable F1 (direct to multi-turn, then to RAG); H3 — a frontier cloud agent fails the full attribution and provenance requirements even when result quality is acceptable; H4 — a curated retrieval pipeline on a local open-weight model running on a single workstation GPU approaches cloud frontier result quality, with auditability arriving as a structural property of the setup. The reference inventory is a single-expert compilation; cross-validation against independent trackers (Platts, WRI, Global Energy Monitor) is future work. Method-quality metrics are largely insensitive to this limitation — the system is designed for cold-start deployment in sectors and countries where such trackers do not yet exist.

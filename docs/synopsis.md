# Synopsis — Beyond RAG: Stateful-Agentic Architectures for Reliable Economic Statistics

Reliable economic statistics are critical infrastructure for applied modelling, and nowhere more so than in the energy transition. Open energy-system models such as PyPSA-ASEAN need power-plant inventories that are complete, accurately dated, and traceable to primary sources — enabling quasi-real-time support for policy analysis in countries where the data landscape changes faster than publication cycles. Yet across most of the world the relevant facts arrive late, incomplete, or under licences that forbid redistribution, even though the underlying information is already public — scattered across project documents, master plans, environmental assessments, operator reports, and press releases. The general problem behind the specific one is older than AI: science needs knowledge, not opinions. Statistical work requires facts that are sourced, reproducible, and auditable, not plausible outputs from a black box.

This paper builds the argument in six steps.

First, the baseline. Submitting a direct query to a large language model produces an inventory-shaped answer, but not one that meets statistical or scientific quality standards. Numbers shift between runs, citations are absent or fabricated, and there is no way to tell which cells one should trust.

Second, the quality bar that any acceptable system must clear. Four properties define it. *Accuracy* asks whether the table contains all assets (recall), only assets (precision), and the correct attributes per asset. *Coherence* asks whether extracted cells are internally consistent: cross-row values do not contradict, and aggregate totals match per-plant sums. *Provenance* — in standard terms, attribution and faithfulness — requires that each cell traces to a specific row of a specific source table; that ideally two independent primary sources back each asset; that citations are verified rather than merely verifiable — aspirational but non-negotiable in v1; that attribution is per-cell rather than per-row; and that the procedure is independent of any single model and incrementally updateable when new documents appear. *Temporality* follows from the nature of energy infrastructure: every value carries a best-effort as-of date, with notable status changes flagged in a notes column; full historical trajectories and scenario projections are the province of the energy model, not the statistical tool.

Third, the method ladder. Each rung addresses one bottleneck in the quality space defined above. *Articulation* — the gap between what an analyst means and what the model answers — is narrowed by prompt engineering and multi-turn exchange; Articulation failures pollute all four properties at once. *Coverage* — facts the model never encountered in training — is the main driver of Accuracy failures; retrieval-augmented generation addresses it by feeding the model relevant documents. *Freshness* — data that post-dates the model's training cutoff — causes Temporality errors; web access reaches it. *Coherence* failures stem from poor synthesis across sources; explicit chain-of-thought reasoning reduces them. The first two rungs are sequential; web access and reasoning arrived in parallel across the industry, both converging at deep research. Together these four rungs bring Accuracy, Temporality, and Coherence within reach. Provenance is not addressed by any of them — it requires a different architecture.

Fourth, even the best current systems confirm the gap. We predict that a state-of-the-art cloud agent given everything in one prompt — extended reasoning, web access, a fully specified extraction prompt — at roughly ten dollars per overnight run will achieve acceptable recall, yet still fail the full provenance requirements: citations verifiable but not verified, attribution per-row not per-cell, no as-of date per value.

Fifth, the full requirements imply a specialised architecture, not a heroic single prompt. Such a system must be stateful, capable of row-level provenance today and per-cell provenance as the target, runnable on local models for sovereignty and cost, and updateable without re-extracting the world. Each cell is a claim: a (source, date, confidence, conflict-resolution history) tuple. Whether a well-chosen local model achieves this without the full deep-research stack, or whether parametric extraction already suffices, remains to be explored.

Sixth, a structural analogy. Each cell in a power-plant inventory — one plant, one attribute, one value — maps to a knowledge-graph triple: subject, predicate, object. Fusing tables from competing sources is therefore the same problem as fusing overlapping triple sets, with the same need for conflict resolution, source authority, and temporal versioning. Cases that rule-based schema-fixed systems cannot handle cleanly — assets mid-lifecycle, contested sources, multilingual records, conditional projections — are where language-model reasoning adds genuine value. This paper works with structured tables; graph databases are a natural next layer.

Four hypotheses make this argument empirical, tested against a hand-curated reference inventory of Vietnam's thermal power sector. H1: multi-turn exchange adds measurable F1 over single-shot extraction on the same task. H2: retrieval augmentation adds measurable F1 over multi-turn alone. H3: a frontier cloud agent achieves acceptable recall yet fails the full provenance bar — citations verifiable but not verified, attribution per-row not per-cell. H4: a local open-weight model on a single workstation GPU approaches cloud frontier quality, with auditability as a structural property of the setup. The benchmark is a first application; the method is designed for cold-start deployment in any sector and country where primary sources are public but no curated tracker yet exists.

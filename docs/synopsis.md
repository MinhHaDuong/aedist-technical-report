# Synopsis — Beyond RAG: Stateful-Agentic Architectures for Reliable Economic Statistics

Reliable economic statistics are critical infrastructure for applied modelling, and nowhere more so than in the energy transition. Open energy-system models such as PyPSA-ASEAN need power-plant inventories that are complete, accurately dated, and traceable to primary sources. Yet across most of the world the relevant facts arrive late, incomplete, or under licences that forbid redistribution, even though the underlying information is already public — scattered across project documents, master plans, environmental assessments, operator reports, and press releases. The general problem behind the specific one is older than AI: science needs knowledge, not opinions. Statistical work requires facts that are sourced, reproducible, and auditable, not plausible outputs from a black box.

This paper builds the argument in six steps.

First, the baseline. Submitting a direct query to a large language model produces an inventory-shaped answer, but not one that meets statistical or scientific quality standards. Numbers shift between runs, citations are absent or fabricated, and there is no way to tell which cells one should trust.

Second, the quality bar that any acceptable system must clear. Three properties define it. *Accuracy* asks whether the table contains all assets (recall), only assets (precision), and the correct attributes per asset. *Provenance* — in standard terms, attribution and faithfulness — requires that each cell traces to a specific row of a specific source table; that two independent primary sources back each asset; that citations are verified rather than merely verifiable (the cited source resolves and an independent check confirms it contains the claim); that attribution is per-cell rather than per-row; and that the procedure is independent of any single model and incrementally updateable when new documents appear. *Temporality* follows from the nature of energy infrastructure: every value carries an *as-of date*, because the same asset passes through announced, under-construction, operating, and retired states over its lifetime; projections of future capacity must be conditional on scenarios, not stated as facts.

Third, the industry trajectory. Retrieval-augmented generation closes the Coverage gap by feeding the model documents it never saw in training. Tool use adds Freshness by reaching the live web. Loop and agent architectures add Coherence and Articulation by letting the system iterate over its own drafts. Each step closes one named limit.

Fourth, even at the frontier the result falls short. A state-of-the-art cloud agent given everything in one prompt — extended reasoning, web access, a fully specified extraction prompt — at roughly ten dollars per overnight run achieves acceptable recall, but fails the attribution and provenance requirements: citations are verifiable but not verified, attribution is per-row not per-cell, and no as-of date is recorded per value.

Fifth, the full requirements imply a specialised architecture, not a heroic single prompt. Such a system must be stateful, agentic, capable of per-cell provenance with as-of dates, runnable on local models for sovereignty and cost, and updateable without re-extracting the world. Each cell is a claim: a (source, date, confidence, conflict-resolution history) tuple, not a bare value.

Sixth, a theoretical frame locates the contribution. Fusing competing source tables into one inventory is structurally analogous to fusing knowledge-graph triples: same subject-predicate-object shape, same conflict-resolution problem. Cases that challenge rule-based systems — assets evolving through lifecycle stages, sources of varying authority, multilingual records, conditional projections — are precisely where language-model reasoning adds value over schema-fixed rules. This paper implements per-cell provenance using LLMs and structured tables; graph databases remain a natural next layer for future work.

Four hypotheses make this argument empirical, tested against a hand-curated reference inventory of Vietnam's thermal power sector where contested values were resolved against primary sources: H1 and H2 — each rung of the method ladder adds measurable F1 (direct to multi-turn, then to RAG); H3 — a frontier cloud agent fails the full attribution and provenance requirements even when result quality is acceptable; H4 — a curated retrieval pipeline on a local open-weight model running on a single workstation GPU approaches cloud frontier result quality, with auditability arriving as a structural property of the setup.

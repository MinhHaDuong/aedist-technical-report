# Resources on thermal power in Vietnam

This directory contains raw documents meant to be used as input for an agentic system designed to produce lists of thermal power plants in Vietnam.

By providing these curated documents, we short-circuit the Discovery, Harvesting and Ranking steps so that development can focus on the knowledge management part.
They are chosen to be challenging to ingest: long documents, multi-page multi-part tables, multi lingual, handbooks, diagrams, screenshots of LinkedIn or other sites...

# Report

LaTeX technical report built with Tectonic (XeTeX engine).

## Build

```
make          # builds report.pdf
make clean    # remove build artifacts
make cleaner  # also remove report.pdf
```

Tables in `inputs/generated/` are auto-generated by
`make -f experiments/render.mk report-tables` from the project root.
Rebuild them before compiling if experiment results have changed.

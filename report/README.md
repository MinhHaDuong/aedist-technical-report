# Report

LaTeX technical report built with Tectonic (XeTeX engine).

## Build

```
make          # builds report.pdf
make clean    # remove build artifacts
make cleaner  # also remove report.pdf
```

Tables in `inputs/generated/` are auto-generated by `make tables` from
the project root. Rebuild them before compiling if experiment results
have changed.

## Structure

| File | Purpose |
|------|---------|
| `report.tex` | Main document |
| `glossaire.tex` | Glossary definitions |
| `refs.bib` | Bibliography (52 entries) |

### Inputs

| Directory | Contents |
|-----------|----------|
| `inputs/documents/` | Source PDFs, images, HTML (see `inputs/README.md`) |
| `inputs/generated/` | Auto-generated LaTeX tables and macros (gitignored) |
| `diagrams/` | Architecture SVG, Mermaid mind-map |
| `Pictures/` | Figures |

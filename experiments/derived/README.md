# Derived analyses

Cross-run analyses computed from primary `outputs/` data.

## Directories

| Directory | Source | Description |
|-----------|--------|-------------|
| `rag_consistency/` | `outputs/rag/` | Majority/union vote consolidated CSVs, summary JSON |
| `verification/` | `outputs/multiturn/`, `outputs/rag/` | Tool-verified and filtered CSVs |

These are not raw LLM outputs — they are computed by post-processing scripts.

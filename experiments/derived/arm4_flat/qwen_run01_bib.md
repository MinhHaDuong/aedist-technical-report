### Annotated Bibliography

- <a id="evn_ar_2010_2011_capacities"></a>**evn_ar_2010_2011_capacities**: Vietnam Electricity (EVN) Annual Report 2010-2011. Primary operator baseline detailing installed capacities and ownership structures prior to the GENCO reorganizations.
- <a id="evn_ar_2017_capacities"></a>**evn_ar_2017_capacities**: Vietnam Electricity Annual Report 2017. Primary source for the post-restructuring GENCO 1, 2, and 3 thermal asset rosters and operational capacities.
- <a id="evn_ar_2018_capacities"></a>**evn_ar_2018_capacities**: Vietnam Electricity Annual Report 2018. Primary operator update capturing the commissioning of major thermal assets like Thái Bình 1 and Vĩnh Tân 4.
- <a id="pdp7_annex1"></a>**pdp7_annex1** & <a id="pdp7_annex2"></a>**pdp7_annex2**: Prime Ministerial Decision 1208/QĐ-TTg (2011). Foundational policy annexes outlining the original PDP7 commissioning schedules and the 2021-2030 forward-looking thermal pipeline.
- <a id="pdp7a_annex1_table1"></a>**pdp7a_annex1_table1**, <a id="pdp7a_annex1_table2"></a>**table2**, <a id="pdp7a_annex1_table3"></a>**table3**: Prime Ministerial Decision 428/QĐ-TTg (2016). Revised PDP7 annexes providing the corrected 2016-2030 commissioning roster, critical for tracking historical delays and BOT project lineage.
- <a id="pdp8_annex2_table1"></a>**pdp8_annex2_table1**, <a id="pdp8_annex2_table2"></a>**table2**, <a id="pdp8_annex2_table3"></a>**table3**, <a id="pdp8_annex2_table4"></a>**table4**, <a id="pdp8_annex2_table5"></a>**table5**: Prime Ministerial Decision 500/QĐ-TTg (2023). The definitive current-policy primary source for PDP8, categorizing LNG, domestic gas, under-construction coal, cogeneration, and delayed/troubled coal projects with explicit implementation notes.
- <a id="report_32_annex1"></a>**report_32_annex1** & <a id="report_58_annex"></a>**report_58_annex**: Government Steering Committee progress reports on revised PDP7 priority projects. Vital secondary implementation sources providing ground-truth schedule evaluations, delay reasoning, and BOT/IPP status tracking.
- <a id="study_e542_pl9_1"></a>**study_e542_pl9_1**, <a id="study_e542_pl9_2"></a>**pl9_2**, <a id="study_e542_pl9_5a"></a>**pl9_5a**: PDP8 Draft 3 Study E-542 Annexes. Technical planning documents mapping the pre-policy option space, regional import-coal site potentials, and long-horizon LNG/thermal candidate projects.
